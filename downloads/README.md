# Демоверсія конфігуратора торгових причепів

1. Завантажте `trading-trailer-demo.zip` кнопкою **Download raw file** на GitHub.
2. Розпакуйте архів.
3. Відкрийте `trading-trailer-demo.html` у Chrome або Edge на комп’ютері.

Встановлювати програми та підключатися до інтернету після завантаження не потрібно. Для 3D потрібен браузер із WebGL.

`trading-trailer-example.pdf` — приклад попередньої пропозиції. Власний PDF створюється кнопкою у конфігураторі після вибору розміру, кольору й комплектації.

Демоверсія використовує надану модель SketchUp; копії адаптовані до шести розмірів із дозволу власника. Габарити — лише корпус, без дишла. Додаткове обладнання показане схематично. Ціни в USD; доставка, податки та остаточне базове оснащення потребують погодження. Розміщення файлів у репозиторії не є публікацією вебсайту.
