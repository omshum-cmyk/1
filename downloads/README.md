# VINVEST — демоверсія 2

VINVEST — демоверсія 2, модель 1000.dae

1. Розпакуйте ZIP.
2. Відкрийте trading-trailer-demo.html у Chrome або Edge на комп’ютері.
3. Обертайте модель, вибирайте розмір, колір та опції.
4. Кнопки під моделлю: ляда, задні двері, поличка, оснащення та горизонтальний розріз. Стулки керуються в розділі «Розсувні стулки вікон».
5. «Зберегти конфігурацію»: у локальному файлі використайте код/JSON. Посилання для інших клієнтів працює після розміщення HTML на сайті; адресу можна вказати в редакторі прайсу.
6. «Прайс»: змініть ціни та завантажте новий HTML із прайсом. Зміни початково діють лише в локальній копії; це не серверна адмінпанель.
7. «Надіслати заявку»: заповніть контакти; підтвердьте надсилання готової чернетки у пошті, Gmail або Telegram. Сам HTML не виконує автоматичне серверне надсилання.
8. PDF з макетом створюється в конфігураторі; у формі заявки доступний PDF із контактами.

Усі габарити — лише корпус, без дишла. Внутрішнє оснащення — приклад і не включене до ціни. Остаточні умови, доставка й податки погоджуються з VINVEST.
Оформлення VINVEST наближене: доступ до vinvest.ua під час роботи був заблокований проксі (403).
